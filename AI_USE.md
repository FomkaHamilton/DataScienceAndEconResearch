# Use of AI in this repository

The research in this repository was carried out with substantial help from an AI assistant. This file states which tools were used, what they did, the rules the work followed, and where the detailed record is kept.

## Tools

Claude (Anthropic), used through Claude Code, a command-line tool that can read and edit files in the repository and run code. Models: Claude Opus 5.5 and Claude Sonnet 5 (October–November 2026). One read-only data check ran on Claude Fable 5.1 and changed no file. Each research-log entry names the model used.

## What the AI assistant did

- searched for and summarized literature, and checked bibliographic details against the sources;
- wrote the data acquisition, cleaning and analysis code, and ran it;
- proposed research designs and analyses for the author to decide on;
- drafted the pre-analysis plan and its addenda, the findings documents, the research-log entries and the manuscript drafts;
- checked the numbers in the manuscript against the output tables, and audited the code.

## What the author does

The author (Thomas Hamilton):

- made the main decisions: which questions to pursue (from candidates the AI assistant proposed), the research design, and what to pre-register;
- reviews the code, the outputs and the citations;
- rewrites the manuscript drafts;
- is responsible for the work.

The author's review is recorded entry by entry: each research-log entry says whether the author has reviewed the work it describes.

## Rules the work follows

- **No fabrication.** No data, sources, citations or results are invented. Every reference is checked against the source itself.
- **Analyses are specified in advance.** The main evaluation follows a pre-analysis plan committed before the test data were used. Later analyses are specified in dated addenda, committed before they were run, and labeled "not pre-specified" when they were chosen after results were known.
- **Prediction is not causation.** Project 1 asks a forecasting question and makes no causal claims.
- **Disclosure** follows the target journal's policy.

## Where the record is

- [research_log.md](research_log.md) at the repository root, and each project's `research_log.md`: dated entries recording each decision, what the AI assistant did, and the author's review status.
- Each project's pre-analysis plan and addenda, and the git history, show what was specified before each analysis was run.

An earlier version of this repository included the full text of the author's working instructions to the AI assistant. It was removed from the current files on 2026-11-09 and remains in the git history. Its research-integrity rules are summarized above.
